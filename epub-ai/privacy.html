隐私说明 / Privacy

你的书，你的密钥，你的机器

这个插件没有账号、没有业务后端，也没有任何统计埋点。书籍与模型配置都保存在你自己的浏览器里；只有当你主动点翻译、摘要或划词时，对应的那段文字才会直接发送到你自己填写的接口。

无需登录 数据不出本机 无第三方脚本 适用于浏览器扩展与本站宣传页面 · 最后更新 2026-09-16

一句话版本：没有账号、没有后端、没有埋点。插件只在你主动触发时，把对应的那段文字发给你自己配置的模型接口，作者这一端什么都看不到。

01我们不收集什么

  • 不要求注册或登录，不收集账号、手机号、邮箱等任何身份信息
  • 不收集你的书籍内容、译文、生词本或阅读记录
  • 不接入统计、广告、崩溃上报等第三方 SDK
  • 本站（宣传页与说明页）不写 Cookie，也不加载第三方脚本

02数据存在哪里

  • 书籍与章节内容：保存在浏览器本地的 IndexedDB 中
  • 模型配置（Provider、Base URL、API Key、Model、提示词）与界面偏好（主题、语言、阅读进度）：保存在浏览器本地的 localStorage 中
  • 这些数据都在你自己的设备上，作者没有任何服务器可以访问它们
  • 在浏览器里清除该扩展的数据、或卸载扩展，这些数据会随之删除

03什么会发送出去，发给谁

  • 只有你主动触发翻译、摘要或划词时，插件才会把「对应的段落文字（或你选中的文字）」连同你的提示词，直接发送到你填写的 Base URL
  • 接收方是你自己选择的模型服务商（OpenAI、DeepSeek、自建中转、本地部署等），其数据处理方式适用该服务商自己的隐私政策
  • 这条链路里没有作者的服务器，也没有任何中转或代理
  • 通过链接导入远程 EPUB 时，请求直接发往你输入的那个地址
  • 没有配置 Base URL、API Key 或 Model 时，插件不会发起任何模型请求

04权限说明

  • storage —— 在本地保存书籍与模型配置
  • sidePanel —— 在浏览器侧边栏中打开阅读界面
  • host_permissions（https://*/* 与 http://*/*）—— 访问你配置的模型地址，以及你粘贴的远程 EPUB 链接
  • 插件不注入内容脚本，也不读取你正在浏览的网页内容

05第三方服务

  • 模型服务商：由你自行选择并填写，数据在你与服务商之间直接交换
  • 远程 EPUB 站点：只有你粘贴其链接时才会被访问
  • GitHub Pages：本站宣传页托管在 GitHub Pages 上，访问日志（如 IP 地址）由 GitHub 按其隐私政策处理

06你的控制权

  • 在书架里删除单本书，或清空整个书架
  • 在设置面板里清除模型配置
  • 卸载扩展，或在浏览器设置中清除该站点的数据
  • 完全不配置模型也能当普通本地阅读器使用，此时不会有任何网络请求

07儿童

本扩展面向一般用户，不针对 13 岁以下儿童设计，也不会主动收集儿童的任何信息。

08变更与联系

本页如有更新，会同时修改顶部的「最后更新」日期。任何疑问或与数据相关的请求，都可以通过 GitHub 或公众号联系作者。

Privacy

Your books, your key, your machine

This extension has no account system, no backend and no analytics. Books and model settings stay in your own browser; only when you explicitly trigger a translation, summary or word lookup does the corresponding text get sent straight to the endpoint you configured.

No login Data stays local No third-party scripts Applies to the browser extension and this site · Last updated 2026-09-16

In one line: no account, no backend, no tracking. The extension only sends the text you asked it to translate or summarize to the model endpoint you configured — the author sees none of it.

01What we do not collect

  • No sign-up or login; no names, phone numbers, email addresses or any other identity data
  • No book content, translations, vocabulary or reading history
  • No analytics, advertising or crash-reporting SDKs
  • This site (landing page and these documents) sets no cookies and loads no third-party scripts

02Where your data lives

  • Books and chapters: in your browser's local IndexedDB
  • Model settings (provider, Base URL, API key, model, prompts) and interface preferences (theme, language, reading progress): in your browser's local storage
  • All of it sits on your own device; the author has no server that can reach it
  • Clearing the extension's data or uninstalling it removes this data

03What leaves your machine, and to whom

  • Only when you trigger translation, summary or word lookup does the extension send the matching paragraph (or your selection) plus your prompt directly to the Base URL you entered
  • The recipient is the model provider you chose (OpenAI, DeepSeek, your own gateway, a local runtime); its own privacy policy applies
  • There is no server of ours and no proxy in that path
  • When you import a remote EPUB by link, the request goes to the URL you pasted
  • With no Base URL, API key or model configured, no model request is made at all

04Permissions

  • storage — keep books and model settings on your device
  • sidePanel — open the reader in the browser side panel
  • host_permissions (https://*/*, http://*/*) — reach the model endpoint you configured and remote EPUB links you paste
  • No content scripts are injected; the extension does not read the pages you browse

05Third parties

  • Your model provider — chosen and configured by you; data moves directly between you and them
  • Remote EPUB hosts — contacted only when you paste their link
  • GitHub Pages — this site is hosted there; access logs (such as IP addresses) are handled under GitHub's privacy policy

06Your controls

  • Delete a single book, or clear the whole library
  • Clear the model configuration in the settings panel
  • Uninstall the extension, or clear its data from your browser settings
  • Use it purely as a local reader with no endpoint configured — then nothing is ever sent

07Children

This extension is aimed at a general audience, is not designed for children under 13, and does not knowingly collect any information from them.

08Changes and contact

If this page changes, the “last updated” date above changes with it. Questions or data-related requests are welcome via GitHub or the WeChat account.
