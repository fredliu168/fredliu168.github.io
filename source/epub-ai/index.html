功能

一个阅读器该有的样子

没有会员墙，没有积分，没有「额度不足」。装上就能用，能用的边界只由你自己配的模型决定。

两种导入

拖拽本地 .epub 文件，或粘贴一个 EPUB 链接直接拉取。解包、解析目录、写库全部在插件里完成。

本地书架

书籍以 Blob 存进 IndexedDB，带阅读进度。支持打开、删除、重新下载，换台设备也不影响本机书库。

段落流式双语

按段落切分请求，译文边生成边回填到原段下方。不整章等，读到哪译到哪，随时可以停下。

整章摘要

一键把当前章节压成几条可带走的线索，先判断这一章值不值得细读，再决定读多深。

划词即译

选中生词或长短语，音标、释义、例句一起给出，还能顺手存进生词本。

直连任意兼容接口

OpenAI、DeepSeek、自建中转、本地 Ollama / vLLM 都行。提示词可编辑，温度与目标语言你说了算。

隐私默认开启

没有账号系统，没有业务后端。章节 HTML 先经 DOMPurify 清洗再渲染，权限只要 storage 与 sidePanel。

五语界面

中文、English、日本語、Deutsch、Français 随时切换，阅读区与设置面板一起跟着变。

住在侧边栏

点一下工具栏图标，侧边栏就打开。它和你的网页并排存在，不用再来回切标签页。

工作原理

四步，全在浏览器里

从拖进文件到看见译文，中间没有一台属于别人的服务器。

  1. 01

    解包

    JSZip 打开 EPUB 容器，fast-xml-parser 解析 OPF 与 NCX，抽出书目信息与完整目录树。

    core/parser
  2. 02

    入库

    Dexie 把书与章节写进 IndexedDB，阅读进度、生词本一同持久化，关掉浏览器也不丢。

    core/db
  3. 03

    渲染

    章节 HTML 经 DOMPurify 清洗，再放进隔离容器排版。目录跳转、字号、双语开关即时生效。

    components/viewer
  4. 04

    翻译

    段落切分后带上你的提示词，流式请求你配置的接口，译文逐段回填；失败自动重试，不打断阅读。

    core/llm

分层清晰，平台相关代码关在门口

解析、模型、存储、界面各自独立，浏览器插件相关逻辑集中在适配层。今天它是侧边栏扩展，明天换一层壳，核心不用重写。

  • adapters/平台适配：扩展桥接 / Web 回退
  • core/EPUB 解析 · LLM 客户端 · IndexedDB
  • store/Zustand 状态：书架、阅读器、设置
  • i18n/五套语言字典，键值统一

你的 Key，你的服务，你的价钱

插件不绑定任何厂商。填上 Base URL 和 API Key，它就是一个纯粹的 OpenAI 兼容客户端。

openai

https://api.openai.com/v1

官方接口，模型列表里的 gpt 系列直接可用。

deepseek

https://api.deepseek.com/v1

custom

本地 Ollama、vLLM、自建中转或任何兼容网关，写地址就行。

安装

三步装进 Chrome

插件以「加载已解压的扩展程序」方式安装，源码在你自己手上。

  1. 1

    拉取源码并安装依赖

    git clone <repo> && cd epub_project_plus npm install
  2. 2

    构建插件产物

    npm run build:ext

    TypeScript 编译 + Vite 打包，清单文件一并输出到 dist/。

  3. 3

    加载扩展

    打开 chrome://extensions，右上角开启「开发者模式」，点「加载已解压的扩展程序」，选择构建出来的 dist/ 目录。

  4. 4

    开始读第一本书

    点击工具栏图标打开侧边栏，在设置里填入 Base URL、API Key 与模型名，然后把一个 EPUB 拖进书架。

它向浏览器要了什么

  • storage保存书籍、阅读进度与模型配置
  • sidePanel在侧边栏里打开阅读界面
  • host_permissions访问你配置的模型地址与远程 EPUB 链接

没有远程代码，没有埋点，没有账号接口。

数据流向只有一条：你主动点翻译或摘要时，对应的段落文字才会发送到你填的那个接口。

常见问题

还是想问的那些事

要注册账号或付费吗？

都不需要。插件本身没有账号体系，也没有会员、积分或邀请。唯一的成本是你在自己模型服务商那里的用量费用。

我的书和 API Key 会被上传吗？

不会。EPUB 文件与 API Key 分别存在浏览器的 IndexedDB 与 chrome.storage.local 里。只有你主动触发翻译、摘要或划词时，相关的段落文本才会发送到你配置的那个接口。

支持哪些大模型？

所有 OpenAI 兼容接口：官方 OpenAI、DeepSeek，以及任何自建或第三方中转；本地跑的 Ollama、vLLM、LM Studio 只要暴露兼容端点也一样能用。

支持哪些 EPUB 文件？

标准 EPUB 2 与 EPUB 3 都可以，本地文件直接拖入，也可以粘贴一个可访问的 EPUB 链接让插件下载。加密或带 DRM 的文件无法解析。

断网还能读吗？

书库、目录、正文阅读和阅读进度完全离线可用；只有翻译与摘要需要能访问你配置的接口。用本地模型时，整条链路都可以不出内网。

界面语言能改吗？

可以。中文、English、日本語、Deutsch、Français 五种界面语言，随时切换，阅读区与设置面板同步生效。

会改我的浏览器设置或读取别的网页吗？

不会。插件只申请 storage 与 sidePanel 两个权限，不注入内容脚本，也不读取你正在浏览的网页内容。

把书架装进侧边栏

一个不打扰你的阅读器：书在本地，译文在眼前，密钥只在你的浏览器里。
